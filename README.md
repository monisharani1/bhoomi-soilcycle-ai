# 🌱 Bhoomi - AI Soil & Crop Cycle Platform

Bhoomi is a full-stack, AI-powered agriculture platform designed to assist farmers and agricultural planners. It features real-time soil detection, crop cycle management, and an AI chatbot for agricultural advice. 

## 🚀 Live Demo
👉 **[Click here to view the live dashboard](https://bhoomi-soilcycle-ai.vercel.app/)**

## 🛠️ Tech Stack & Architecture
This project uses a decoupled architecture with a React frontend and an Express backend:
* **Frontend:** React (Vite), TailwindCSS, Leaflet Maps.
* **Backend:** Node.js, Express, deployed on Render.
* **AI Integrations:** Custom API endpoints for soil analysis and chatbot features.
* **Features:** OTP Authentication, Building detection via Overpass API, Interactive Map integration.

## ⚙️ How to Run Locally
1. Clone the repository.
2. **Backend:** Navigate to `server`, run `npm install`, and start with `node index.js`.
3. **Frontend:** Navigate to the root folder, run `npm install`, and start with `npm run dev`.
